One line, at most 200 characters, that makes a meeting-that-should-have-been-an-email funny: an hour-long meeting about the email nobody read, ending with a second email nobody will read.

## Run it

```sh
python3 main.py
```

The program writes the single joke line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
